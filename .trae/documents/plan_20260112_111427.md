## FastDFS 上传下载接口修改计划

### 目标
将 FastDFS 上传下载接口从使用 docker 命令改为直接使用 Python `fdfs_client` 库连接 FastDFS 服务。

### 修改步骤

#### 1. 修改后端 FastDFS 上传接口
**文件**: `backend/app/api/v1/endpoints/fastdfs.py`

修改内容：
- 移除 docker 命令调用
- 使用 `fdfs_client.client.Fdfs_client` 库直接连接 FastDFS
- 根据前端传递的 `trackerServer` 和 `port` 动态生成客户端配置
- 使用 `client.upload_by_filename()` 上传文件到 FastDFS

#### 2. 修改后端 FastDFS 删除接口
**文件**: `backend/app/api/v1/endpoints/fastdfs.py`

修改内容：
- 同样使用 `fdfs_client` 库
- 使用 `client.delete_file()` 删除文件

#### 3. 修改后端 FastDFS 下载接口（如有需要）
检查是否需要添加下载接口用于测试验证。

#### 4. 测试验证
- 运行单元测试 `test_fdfs.py` 验证上传下载功能
- 前端测试图片上传功能

### 技术要点
- FastDFS 客户端库：`fdfs_client.client.Fdfs_client`
- 初始化方式：`Fdfs_client(config_dict)` 或 `Fdfs_client('conf_path')`
- 上传方法：`client.upload_by_filename(file_path)`
- 删除方法：`client.delete_file(file_id)`
- 配置字段：`tracker_server`、`port`、`http.server_addr`
