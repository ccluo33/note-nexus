## 平滑过渡到网页版计划

### 问题分析
1. **当前项目结构**：基于 Next.js 的应用，使用 App Router 结构
2. **Tauri 相关依赖**：
   - `@tauri-apps/plugin-http`
   - `@tauri-apps/plugin-opener`
3. **浏览器适配层**：
   - `src/lib/browser-adapter` 目录，用于替代 Tauri API
   - 使用 IndexedDB 模拟文件系统
   - 已经有 `isBrowser` 变量检测浏览器环境
4. **代码中的 Tauri 调用**：
   - 可能存在直接调用 Tauri API 的地方
   - 需要确保所有 API 调用都通过 browser-adapter 层

### 修复计划
1. **移除 Tauri 依赖**：
   - 从 `package.json` 中移除 Tauri 相关依赖
   - 运行 `npm install` 更新依赖

2. **检查并修改 Tauri 特定代码**：
   - 检查 `control-link.tsx` 中的 Tauri HTTP 调用
   - 检查其他文件中可能的 Tauri API 调用
   - 确保所有 API 调用都通过 browser-adapter 层

3. **优化 browser-adapter 层**：
   - 移除不必要的代码
   - 确保所有功能在浏览器环境中正常工作
   - 优化 IndexedDB 文件系统实现

4. **测试应用**：
   - 确保所有功能在浏览器环境中正常工作
   - 测试文件系统操作
