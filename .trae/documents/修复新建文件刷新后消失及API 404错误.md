## 问题分析

1. **文件消失问题**：在`loadCollapsibleFiles`函数中，加载文件夹子文件时未设置完整的`path`属性，导致文件无法被正确关联到父文件夹。
2. **API 404错误**：向量数据库操作时使用了错误的文件路径，与文件消失问题相关联。

## 修复方案

### 1. 修复`loadCollapsibleFiles`函数中的文件路径设置
在`src/stores/article.ts`的`loadCollapsibleFiles`函数中，为加载的子文件添加完整路径属性：

- 为自定义工作区加载的文件添加`path`属性
- 为默认工作区加载的文件添加`path`属性
- 确保路径格式为`parentPath/filename`

### 2. 修复代码位置
- **文件**：`src/stores/article.ts`
- **函数**：`loadCollapsibleFiles`
- **行号**：654-682行

### 3. 修复内容
在创建子文件`DirTree`对象时，添加`path`属性设置：
```typescript
// 自定义工作区
children = (await readDir(fullFolderPath))
  .filter(/* 过滤条件 */)
  .map(file => ({
    // 其他属性
    path: `${fullpath}/${file.name}`, // 添加完整路径
    // 其他属性
  })) as DirTree[]

// 默认工作区
children = (await readDir(pathOptions.path, { baseDir: pathOptions.baseDir }))
  .filter(/* 过滤条件 */)
  .map(file => ({
    // 其他属性
    path: `${fullpath}/${file.name}`, // 添加完整路径
    // 其他属性
  })) as DirTree[]
```

## 预期效果

1. 新建文件保存后，刷新浏览器再打开目录时，文件将正确显示
2. 向量数据库操作时使用正确的文件路径，不再出现API 404错误
3. 文件与文件夹的关联关系将被正确维护
