## FastDFS 连接问题修复计划

### 问题原因
Python 进程通过 `127.0.0.1:22122` 连接到 tracker，但 tracker 返回的 storage 地址是 Docker 内部 IP `172.18.0.3:23000`，导致 Python 进程无法访问。

### 解决方案

1. **停止并删除现有的 FastDFS 容器**

2. **使用 host 网络模式重新运行 storage 容器**，这样 storage 会使用宿主机的网络接口

3. **修改后端配置文件 `backend/client.conf`**，将 `tracker_server` 改为 `0.0.0.0:22122` 或 `172.20.10.11:22122`

4. **重新测试上传功能**

### Docker 命令

```bash
# 停止旧容器
docker stop fastdfs_tracker_container fastdfs_storage_container
docker rm fastdfs_tracker_container fastdfs_storage_container

# 重新运行 tracker（使用host网络）
docker run -d --name fastdfs_tracker_container --net=host -v /var/fdfs/tracker:/var/fdfs delron/fastdfs tracker

# 重新运行 storage（使用host网络，绑定到127.0.0.1）
docker run -d --name fastdfs_storage_container --net=host -v /var/fdfs/storage:/var/fdfs -e TRACKER_SERVER=127.0.0.1:22122 -e GROUP_NAME=group1 delron/fastdfs storage
```
