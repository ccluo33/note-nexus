# 优化设置页面切换速度

## 问题分析

当前设置页面切换缓慢的主要原因：
1. **独立页面路由**：每个设置项都是独立的 Next.js 页面，切换时触发完整的页面加载
2. **复杂组件树**：每个设置页面包含大量组件，特别是 AI 设置页面
3. **重复初始化**：切换页面时重新初始化所有状态和组件
4. **缺乏组件懒加载**：所有组件在页面加载时一次性渲染

## 优化方案

### 1. 客户端路由优化

将设置页面从多个独立页面改为单个页面内的条件渲染：

```typescript
// 修改 setting/layout.tsx
import { SettingTab } from "./components/setting-tab"

// 导入所有设置页面组件
import GeneralSettingsPage from "./general/page"
import AiPage from "./ai/page"
import SyncPage from "./sync/page"
// 其他设置页面...

export default function SettingLayout({
  children,
}: {
  children: React.ReactNode
}) {
  const [activeTab, setActiveTab] = useState('general')
  
  return (
    <div id="setting-page" className="flex h-full">
      <SettingTab onTabChange={setActiveTab} />
      <div className="flex-1 p-8 overflow-y-auto h-full">
        {/* 根据 activeTab 条件渲染不同的设置页面 */}
        {activeTab === 'general' && <GeneralSettingsPage />}
        {activeTab === 'ai' && <AiPage />}
        {activeTab === 'sync' && <SyncPage />}
        {/* 其他设置页面... */}
      </div>
    </div>
  )
}
```

### 2. 组件懒加载

使用 React.lazy 和 Suspense 懒加载设置页面组件：

```typescript
// 修改 setting/layout.tsx
import { Suspense, useState } from 'react'
import { SettingTab } from "./components/setting-tab"

// 懒加载所有设置页面组件
const GeneralSettingsPage = React.lazy(() => import("./general/page"))
const AiPage = React.lazy(() => import("./ai/page"))
const SyncPage = React.lazy(() => import("./sync/page"))
// 其他设置页面...

export default function SettingLayout({
  children,
}: {
  children: React.ReactNode
}) {
  const [activeTab, setActiveTab] = useState('general')
  
  return (
    <div id="setting-page" className="flex h-full">
      <SettingTab onTabChange={setActiveTab} />
      <div className="flex-1 p-8 overflow-y-auto h-full">
        <Suspense fallback={<div className="flex items-center justify-center h-full">加载中...</div>}>
          {/* 根据 activeTab 条件渲染不同的设置页面 */}
          {activeTab === 'general' && <GeneralSettingsPage />}
          {activeTab === 'ai' && <AiPage />}
          {activeTab === 'sync' && <SyncPage />}
          {/* 其他设置页面... */}
        </Suspense>
      </div>
    </div>
  )
}
```

### 3. 优化 SettingTab 组件

修改 SettingTab 组件，使用本地状态管理当前选中的标签，避免不必要的路由跳转：

```typescript
// 修改 components/setting-tab.tsx
export function SettingTab({ onTabChange }: { onTabChange: (anchor: string) => void }) {
  const [currentPage, setCurrentPage] = useState('general')
  const t = useTranslations('settings')
  
  // Add translations to the config
  const config = baseConfig.map(item => {
    if (typeof item === 'string') return item
    return {
      ...item,
      title: t(`${item.anchor}.title`)
    }
  })

  function handleNavigation(anchor: string) {
    setCurrentPage(anchor)
    onTabChange(anchor)
  }
  
  return (
    <div className="flex flex-col w-56 justify-between h-full bg-sidebar border-r">
      <ul className="w-full p-4 flex flex-col justify-between flex-1 overflow-y-auto">
        {config.map((item, index) => {
          if (typeof item === 'string') return <Separator key={index} className="my-2" />
          return (
            <li
              key={item.anchor}
              className={currentPage === item.anchor ? '!bg-zinc-800 text-white setting-anchor' : 'setting-anchor'}
              onClick={() => handleNavigation(item.anchor)}
            >
              {item.icon}
              <span>{item.title}</span>
            </li>
          )
        })}
      </ul>
    </div>
  )
}
```

### 4. 移除不必要的初始化逻辑

检查并移除组件中不必要的初始化逻辑，特别是 useEffect 中的重复初始化：

```typescript
// 优化 ai/page.tsx 中的初始化逻辑
useEffect(() => {
  async function init() {
    const store = await Store.load('store.json');
    const aiModelList = await store.get<AiConfig[]>('aiModelList')
    
    if (aiModelList) {
      // 迁移旧配置
      const migratedList = aiModelList.map(migrateOldConfig)
      
      // 检查是否有配置被迁移，如果有则保存
      const hasChanges = migratedList.some((config, index) => 
        JSON.stringify(config) !== JSON.stringify(aiModelList[index])
      )
      
      if (hasChanges) {
        await store.set('aiModelList', migratedList)
        setAiModelList(migratedList)
      }
    }
    
    // 过滤出用户自定义模型
    const userModels = aiModelList?.filter(model => !noteGenModelKeys.includes(model.key)) || []
    
    // 如果已经有保存的选择，且该配置仍然存在，则使用它
    if (selectedAiConfig && userModels.find(model => model.key === selectedAiConfig)) {
      // 已经有保存的选择，不需要做任何事情
      return
    } else if (userModels.length > 0) {
      // 如果没有保存的选择或选择的配置不存在，选择第一个
      const firstUserModel = userModels[0]
      setSelectedAiConfig(firstUserModel.key)
    } else {
      // 如果没有用户自定义模型，清空选择
      setSelectedAiConfig('')
    }
  }
  init()
}, [])
```

## 预期效果

1. **切换速度提升**：客户端条件渲染替代页面路由，切换时间从秒级缩短到毫秒级
2. **初始加载优化**：懒加载减少初始页面加载时间
3. **资源占用降低**：只渲染当前选中的设置页面，减少内存占用
4. **用户体验改善**：流畅的切换体验，无明显加载延迟
